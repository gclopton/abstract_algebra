

## Some finiteness properties


> [!definition] Definition: Locally noetherian and noetherian scheme
> Say that $X$ is locally noetherian if there exists a covering $X=\bigcup \operatorname{Spec} A_i$ such that each $A_i$ is a noetherian ring.
> Say that $X$ is noetherian if it is both locally noetherian and quasi-compact.


> [!NOTE]
> $X$ is noetherian $\Longleftrightarrow$ there is a finite covering $X=\bigcup_i$ Spec $A_i$ where each $A_i$ is noetherian.




> [!proposition] Proposition 19: Characterization of locally noetherian
> $X$ is locally noetherian iff for any affine open Spec $R \subseteq X$, the ring $R$ is noetherian.


**Proof:** We verify that the property "Spec $A \subset X$ is noetherian" is affine-local (so Lemma 18 applies).
(i) If Spec $R=U \subset X$ is open and $R$ is noetherian, then $R_f$ is noetherian for any $f \in R$.
(ii) Suppose Spec $R=\bigcup D\left(f_i\right)$ is a finite covering where each $\operatorname{Spec}\left(R_{f_i}\right)$ is noetherian. We show any ideal $I \subset R$ is finitely generated. For each $i$ the extension

$$
J_i:=I R_{f_i} \subset R_{f_i}
$$

is finitely generated. Let

$$
\frac{x_{i j}}{f_i^{n_{i j}}} \quad\left(j=1, \ldots, r_i\right)
$$

be generators of $J_i$ with $x_{i j} \in I$. Consider the ideal $M \subset R$ generated by all $x_{i j}$.



Then $M_{f_i}=I_{f_i}$ for each $i$. Hence

$$
(I / M)_p \cong(I / M) \otimes_R R_p=0 \quad \text { for all } \mathrm{p} \in \operatorname{Spec} R .
$$


Therefore $I / M=0$, so $I=M$ is finitely generated. $\square$

> [!NOTE] Recall: Finite/f.g./f.p. ring maps.
> A ring map $f: A \rightarrow B$ is
> (a) finite if $B$ is finitely generated as an $A$-module;
> (b) finitely generated if $B \cong A\left[x_1, \ldots, x_n\right] / I$ as an $A$-algebra;
> (c) finitely presented if $B \cong A\left[x_1, \ldots, x_n\right] / I$ where $I$ is a finitely generated ideal.




> [!definition] finite morphism
> Let $f: X \rightarrow S$.
> 
> 
> $f$ is finite if for any affine open $U=\operatorname{Spec} A \subset S$, the preimage $f^{-1}(U)$ is affine and the induced map
> 
> $$
> \Gamma\left(U, \mathcal{O}_S\right) \rightarrow \Gamma\left(f^{-1}(U), \mathcal{O}_X\right)
> $$
> 
> is finite.
> 




> [!definition] Locally of Finite Type Morphism
> $f$ is locally of finite type if for any affine open $U=$ Spec $A \subset S$ and any affine open $V \subset f^{-1}(U)$, the map
> 
> $$
> \Gamma\left(U, \mathcal{O}_S\right) \longrightarrow \Gamma\left(V, \mathcal{O}_X\right)
> $$
> 
> is finitely generated.



> [!definition] Locally Finitely Presented Morphism
> $f$ is locally finitely presented if, in the same situation, the map
> 
> $$
> \Gamma\left(U, \mathcal{O}_S\right) \longrightarrow \Gamma\left(V, \mathcal{O}_X\right)
> $$
> 
> is finitely presented.



> [!example] Example: A finite map by squaring


Consider $\mathrm{A}_{\mathrm{C}}^1 \rightarrow \mathrm{~A}_{\mathrm{C}}^1$ induced by

$$
\mathbf{C}[u] \longrightarrow \mathbf{C}[t], \quad u \longmapsto t^2 .
$$


This map is finite: as a $\mathbf{C}[u]$-module, $\mathbf{C}[t]$ is finitely generated; generators are $1, t$.



> [!NOTE]
> From the definition as stated, it isn't immediate that the induced map of schemes is finite; we will shortly state the proposition that being finite is an affine-local property: if on one affine cover the structure sheaf rings are finite algebras, then on any affine cover they are finite algebras. In particular, a finite ring map $(A \rightarrow B)$ induces a finite morphism of schemes Spec $B \rightarrow$ Spec $A$.

> [!theorem] Proposition 20: Affine-locality of "finitely generated / finitely presented" for $\boldsymbol{A}$-algebras
> Let $\boldsymbol{A}$ be a commutative ring. The property of an $\boldsymbol{A}$-algebra being finitely generated (resp. finitely presented) is affine-local. That is:
> (i) If $B$ is a finitely generated $A$-algebra, then so is $B_g$ for any $g \in B$. (Likewise for finitely presented.)
> (ii) If $\left(g_1, \ldots, g_n\right)=B$ and each $B_{g_i}$ is a finitely generated $A$-algebra (resp. finitely presented), then $B$ is finitely generated (resp. finitely presented).


**Proof:** We treat the finitely generated case and omit the finitely presented case (it takes a bit more work).
(i) If $x_1, \ldots, x_r$ are $A$-algebra generators of $B$, then $x_1, \ldots, x_r, \hat{g}$ generate $B_g$ as an $A$-algebra.
(ii) Write $1=\sum b_i g_i$ (possible since $\left(g_i\right)=B$ ). For each $i, B_{g_i}$ is a finitely generated $A$-algebra, so there are finitely many elements $\left\{x_{i j} / g_i^m\right\}$ which generate $B_{g_i}$ as an $A$-algebra. Write $x_{i j}=c_{i j} / g_i^m$ with $c_{i j} \in B$ (take a common $m$ independent of $i, j$ ).

Consider the $A$-subalgebra

$$
R:=A\left\langle b_i g_i, c_{i j}\right\rangle \subset B .
$$


We will show $R=B$. Note that $R_{g_i}=B_{g_i}$ for each $i$. Let $\mathrm{p} \subset B$ be a prime. Since $\left(g_1, \ldots, g_n\right)=B$, some $g_i \notin \mathfrak{p}$; then

$$
(B / R)_{\mathrm{p}} \cong(B / R)_{g_{\mathrm{i}}}=0
$$


Thus $(B / R)_{\mathrm{p}}=0$ for all primes p , hence $B / R=0$ and $B=R$. Therefore $B$ is finitely generated over A. .




> [!proposition] Proposition 21: Affine-locality on the base for finiteness conditions
> Let $f: X \rightarrow S$ be a morphism of schemes. The property that $f$ is finite / locally of finite type / locally of finite presentation is affine-local on $S$. In particular:
> (a) $f$ is finite $\Longleftrightarrow$ there exists an affine open cover $S=\bigcup$ Spec $\boldsymbol{A}_i$ such that for each $i$,
> 
> $$
> f^{-1}\left(\operatorname{Spec} A_i\right) \text { is affine and equals } \operatorname{Spec}\left(B_i\right)
> $$
> 
> with $B_i$ a finite $A_i$-module.
> (b) $\boldsymbol{f}$ is locally of finite type (resp. locally of finite presentation) $\Longleftrightarrow$ there exists an affine open cover $S=\bigcup$ Spec $A_i$ such that for each $i, f^{-1}$ (Spec $A_i$ ) admits an affine open cover by spectra of finitely generated (resp. finitely presented) $A_i$-algebras.



**Proof:** 
(a) postponed.
(b) " $\Rightarrow$ " is clear. For " $\Leftrightarrow$ ", we show:
(i) If Spec $A \subset S$ is affine and $f^{-1}(\operatorname{Spec} A) \rightarrow \operatorname{Spec} A$ is locally of finite type (resp. f.p.), then for every $g \in A$,

$$
f^{-1}\left(\operatorname{Spec} A_g\right) \longrightarrow \operatorname{Spec} A_g
$$

is also locally of finite type (resp. f.p.).
(ii) If $\left(g_1, \ldots, g_n\right)=A$ and each

$$
f^{-1}\left(\operatorname{Spec} A_{g_i}\right) \longrightarrow \operatorname{Spec} A_{g_i}
$$

is locally of finite type (resp. f.p.), then so is

$$
f^{-1}(\operatorname{Spec} A) \longrightarrow \operatorname{Spec} A .
$$


> [!Note]
> By Proposition 20 and Lemma 18: if $f^{-1}$ (Spec $R$ ) has an affine open cover by spectra of finitely generated (resp. finitely presented) $R$-algebras, then
> 
> $$
> f^{-1}(\operatorname{Spec} R) \longrightarrow \operatorname{Spec} R
> $$
> 
> is locally of finite type (resp. locally of finite presentation).



**(i) Let $\operatorname{Spec} B \subset f^{-1}\left(\operatorname{Spec} A_g\right)$ be an affine open:**

Since $f^{-1}\left(\operatorname{Spec} A_g\right) \subset f^{-1}(\operatorname{Spec} A)$ is open, by assumption $B$ is a finitely generated (resp. f.p.) $A$ algebra. It follows that $B_g$ is a finitely generated (resp. f.p.) $A_g$-algebra.

**(ii) Let $\operatorname{Spec} B \subset f^{-1}(\operatorname{Spec} A)$ be affine open:**

Let $b_1, \ldots, b_r \in B$ be the images of $g_1, \ldots, g_r$ under the ring map $A \rightarrow B$. Then $\left(b_1, \ldots, b_r\right)=B$. For each $i$,

$$
\operatorname{Spec}\left(B_{b_i}\right)=f^{-1}\left(\operatorname{Spec} A_{g_i}\right)
$$

is an open affine, so by the assumption $B_{b_i}$ is a finitely generated (resp. f.p.) $A_{g_i}$-algebra. Since each $A_{g i}$ is a finitely generated (resp. f.p.) $A$-algebra, we conclude that each $B_{b_i}$ is a finitely generated (resp. f.p.) $A$-algebra. By Proposition 20, $B$ is then a finitely generated (resp. f.p.) $A$-algebra as well. $\square$



# Quasi-compact and finite-type morphisms


> [!example] Quasi-compact morphism
> Say that $f: X \rightarrow S$ is quasi-compact if there exists an open covering $X=\bigcup$ Spec $A_i$ such that each preimage $f^{-1}\left(\operatorname{Spec} A_i\right)$ is quasi-compact.



> [!exercise]
> Equivalently, $f^{-1}(V)$ is quasi-compact for every quasi-compact open $V \subset S$.



> [!definition] Finite type morphism
> A morphism $f: X \rightarrow S$ is finite type if it is locally of finite type and quasi-compact.



> [!example] Examples
> 1. For a morphism $f: X \rightarrow S=\operatorname{Spec} R, f$ is quasi-compact $\Longleftrightarrow X$ is quasi-compact.
> 2. Any closed immersion is quasi-compact and locally of finite type (hence it is finite type).




> [!NOTE]
> A finitely presented morphism $X \rightarrow S$ is not just "locally finitely presented + quasi-compact"; there is an additional condition (to be introduced later).
