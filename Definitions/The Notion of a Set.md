
**The problem with trying to formally define a set:**
- A **set** is a well-defined collection of objects.
	- What is a collection? "an aggregate of things?". What is an aggregate?
	- Our definition is circular so it is worthless
	- Mathematicians realize that there must be some undefined or primitive concept with which to start. At the moment, they have agreed that set shall be such a primitive concept.


**Facts about Sets:**
1.) **_element notation:_** A set $S$ is made up of elements, and if $a$ is one of these elements, we shall denote this fact by $a \in S$.
2.) **_the empty set:_** There is exactly one set with no elements. It is the empty set and is denoted by $\varnothing$.
3.) **_two ways to describe a set:_** We may describe a set either by giving a characterizing property of the elements, such as "the set of all members of the United States Senate," or by listing the elements.
- _set builder notation:_ If a set is characterized by a property $P(x)$ then we can use notation called "set builder notation", $\{x \mid P(x)\}$ which is read "the set of all x such that the statement about $P(x)$ is true".
4.) **_well defined set:_** A set is _well defined_, meaning that if $S$ is a set and $a$ is some object, then either $a$ is definitely in $S$ denoted $a \in S$ or $a$ is definitely not in $S$, denoted $a \notin S$.
