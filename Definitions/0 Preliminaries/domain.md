
The set $A$ from which inputs to the function $f: A \rightarrow B$ are taken.

---

# Examples

## Continuous-variable domains
- $f(x)=x^2$ (real-valued). Domain $=\mathbb{R}$.
- $g(x)=\frac{1}{x-2}$. Domain $=\mathbb{R} \backslash\{2\}$ (exclude the pole).
- $h(x)=\sqrt{1-x^2}$ (over the reals). Domain $=[-1,1]$.
- $\ln x$. Domain $=(0, \infty)$.
- $\Gamma(z)$ (the gamma function). Domain $=\mathbb{C} \backslash\{0,-1,-2, \ldots\}$.

## Discrete / finite domains
- Factorial $n$ !. Domain $=\mathbb{N}=\{0,1,2, \ldots\}$.
- Parity $p(n)=n \bmod 2$. Domain $=\mathbb{Z}$.
- A finite-set function: $f:\{$ red, green, blue $\} \rightarrow\{0,1\}$ with $f($ red $)=1, f($ green $)= 0, f($ blue $)=1$. Domain = \{red, green, blue\}.
- Modular multiplication: $m([x])=[3 x]$ on $\mathbb{Z} / 7 \mathbb{Z}$. Domain $=\mathbb{Z} / 7 \mathbb{Z}$ (the seven residue classes).
- Word length: $\ell(w)=$ "number of characters in $w^{\prime \prime}$. Domain $=\Sigma^*$ (all finite strings over an alphabet $\Sigma$ ; discrete when $\Sigma$ is finite).

## Other structured domains
- Determinant $\operatorname{det}(A)$. Domain $=M_n(\mathbb{R})$ (all $n \times n$ real matrices).
- Cardinality on a power set: $F(A)=|A|$. Domain $=\mathcal{P}(S)$ (all subsets of a fixed set $S$; finite/discrete if $S$ is finite).
