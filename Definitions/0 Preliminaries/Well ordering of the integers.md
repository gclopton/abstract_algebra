
Every nonempty subset $A \subseteq \mathbb{Z}^{+}$(the positive integers) has a least element; that is, there exists $m \in A$ with $m \leq a$ for all $a \in A$. 



## Why $\mathbb{Z}$ with the usual order is not well-ordered?

$\mathbb{Z}$ with its usual order $\leq$ is not well-ordered because there are nonempty subsets with no least element. The simplest witness is the set of all negative integers $\{\ldots,-3,-2,-1\}$. If you propose any candidate $m$ from that set, then $m-1$ is also in the set and is smaller, so no least element exists. Equivalently, $\mathbb{Z}$ contains an infinite strictly decreasing chain $0>-1>-2>\cdots$, and a well-ordered set cannot have such chains.
