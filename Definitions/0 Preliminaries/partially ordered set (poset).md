
A partial order on a set $P$ is a binary relation $\leq$ satisfying three axioms for all $x, y, z \in P$ :
1. Reflexive: $x \leq x$.
2. Antisymmetric: if $x \leq y$ and $y \leq x$, then $x=y$.
3. Transitive: if $x \leq y$ and $y \leq z$, then $x \leq z$.

The pair ( $P, \leq$ ) is called a partially ordered set or poset. Elements $x, y$ are comparable if $x \leq y$ or $y \leq x$; otherwise they are incomparable. A common "strict" version is $x<y$ defined by $x \leq y$ and $x \neq y$; this is irreflexive and transitive.
